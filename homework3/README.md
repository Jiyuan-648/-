3. 代码排错记录
出现问题
任务 5 导出 txt 文档时，车辆编号、驾驶员编号末尾全都带.0，比如 9132.0，不是纯整数，不符合输出格式要求。
排查与解决过程
找问题根源：打开原始 ICData.csv 查看，驾驶员编号这一列存在空值，pandas 读取文件时自动识别成浮点型数据，输出文件时就会多出小数点。
第一种尝试：读取 csv 时直接指定驾驶员编号为整数类型，但是读取操作在数据清洗之前，空值无法转为 int，程序直接报错，这个方案行不通。
最终可行办法：在写入 txt 文件那一步，读取每一行数据时手动把车辆、驾驶员编号强制转成整数再写入，不会影响前面的数据统计，输出也没有小数点。
验证结果：重新运行代码，打开生成的 1101.txt 查看，两行编号全部为纯数字整数，格式达标。
4. 核心代码逐行中文注释
下面是任务 4 计算 PHF 高峰小时系数的关键代码，我自己逐行加上注释理解逻辑：
python
运行
# 第一步：自动找出全天客流高峰时段
# 筛选上车数据，按小时分组，统计每个小时刷卡总人次
hourly_counts = boarding.groupby("hour").size()
# 找出刷卡人数最多的小时数字（0-23），作为高峰小时
peak_hour = hourly_counts.idxmax()
# 提取高峰小时对应的总刷卡数量
peak_hour_count = hourly_counts.max()

# 打印输出高峰时段范围和客流总数
print(f"高峰小时：{peak_hour:02d}:00 ~ {peak_hour + 1:02d}:00，刷卡量：{peak_hour_count} 次")

# 单独筛选出高峰一小时内所有刷卡记录，复制新表避免修改原数据
peak_hour_data = boarding[boarding["hour"] == peak_hour].copy()
# 从完整交易时间里提取分钟信息，用来划分5/15分钟时段
peak_hour_data["minute"] = peak_hour_data["交易时间"].dt.minute

# 计算5分钟粒度客流，求解PHF5
# 整除5再乘5，把分钟归到对应5分钟区间起点（例：7→0，12→10）
peak_hour_data["min5_bin"] = (peak_hour_data["minute"] // 5) * 5
# 按5分钟区间分组统计人次
min5_counts = peak_hour_data.groupby("min5_bin").size()
# 找到高峰一小时内，人流量最大的5分钟时段数据
max_5min_count = min5_counts.max()
max_5min_start = min5_counts.idxmax()
max_5min_end = max_5min_start + 5

# PHF5计算公式：高峰小时总客流 ÷（12 × 最大5分钟客流）
# 一小时总共可以划分12个5分钟区间
phf5 = peak_hour_count / (12 * max_5min_count)

# 计算15分钟粒度客流，求解PHF15
# 整除15取整，划分四个15分钟大区间
peak_hour_data["min15_bin"] = (peak_hour_data["minute"] // 15) * 15
# 统计每个15分钟窗口刷卡人数
min15_counts = peak_hour_data.groupby("min15_bin").size()
# 提取客流最高的15分钟窗口数据
max_15min_count = min15_counts.max()
max_15min_start = min15_counts.idxmax()
max_15min_end = max_15min_start + 15

# PHF15计算公式：高峰小时总客流 ÷（4 × 最大15分钟客流）
# 一小时包含4个15分钟时段
phf15 = peak_hour_count / (4 * max_15min_count)
代码知识点总结
// 5 * 5 是取整划分时间段的常用写法，把零散分钟归到固定区间开头；
PHF 数值区间在 0 到 1 之间，数值越接近 1，代表高峰一小时内客流分布越均匀；数值越小，说明短时间内客流扎堆，存在明显客流尖峰；
分母固定 12 和 4，分别对应 60 分钟里 5 分钟、15 分钟窗口的总数。
